# Lease Advisory Expertise

## Lease Structure Overview

### Key Lease Terms

| Term | Description |
|------|-------------|
| **Term** | Length of lease (e.g., 10 years) |
| **Rent** | Passing rent per annum |
| **Review Pattern** | When rent can be adjusted (e.g., 5-yearly) |
| **Break Clause** | Option to end lease early |
| **Repairs** | FRI (Full), IRI (Internal), or Schedule |
| **User Clause** | Permitted uses |
| **Alienation** | Assignment/subletting rights |
| **Security of Tenure** | 1954 Act protection |

### Common Lease Lengths

| Property Type | Typical Term |
|---------------|--------------|
| Prime Retail | 10-15 years |
| Secondary Retail | 5-10 years |
| Office | 5-10 years |
| Industrial | 5-15 years |
| Flexible/Serviced | 1-3 years |

## Rent Reviews

### Review Basis

**Upward Only (Most Common)**
- Rent can only stay same or increase
- Cannot fall below current rent
- Market Value basis

**Open Market**
- Rent moves to market level
- Can go up or down
- Less common in UK

**RPI/CPI Linked**
- Fixed % or index-linked increases
- Provides certainty
- May not track market

### Rent Review Process

**1. Trigger Notice** (Time of Essence?)
- Check if landlord must serve notice
- Check time limits
- Time rarely of essence in modern leases

**2. Counter-Notice**
- Tenant response if required
- Often advisory, not mandatory

**3. Negotiations**
- Exchange evidence
- Without prejudice discussions
- Negotiate settlement

**4. Resolution**
- Agreement: Memorandum signed
- Dispute: Third party determination

### Comparable Evidence

**Hierarchy of Evidence:**
1. Open market lettings (same building)
2. Open market lettings (comparable buildings)
3. Lease renewals
4. Rent reviews (less reliable)
5. Rent free equivalents

**Adjustments Required:**
- Lease terms (length, breaks)
- Specification differences
- Incentives (rent-free, fit-out)
- Date (time adjustment)

### Rent Review Calculation

```
Subject Property: 5,000 sq ft Grade B office, Sheffield CC

Comparable Analysis:
| Property | Rent (£/sf) | Adjustment | Adjusted |
|----------|-------------|------------|----------|
| Comp A | £22.00 | -5% spec | £20.90 |
| Comp B | £21.50 | Level | £21.50 |
| Comp C | £23.00 | -10% size | £20.70 |

Analysis: £20.70 - £21.50 per sq ft
Recommendation: £21.00 per sq ft (£105,000 pa)
```

## Lease Renewals (1954 Act)

### Protected Tenancies

Tenant has right to new lease unless:
- Landlord proves ground for opposition
- Lease "contracted out" of Act

### Renewal Timetable

| Action | Timing |
|--------|--------|
| Section 25 Notice (L) | 6-12 months before expiry |
| Section 26 Request (T) | 6-12 months before expiry |
| Counter-notice | Within 2 months |
| Court application | Before notice expiry |
| New lease from | End of statutory period |

### Landlord Opposition Grounds

| Ground | Description | Compensation? |
|--------|-------------|---------------|
| (a) | Tenant breach - repairs | No |
| (b) | Persistent rent arrears | No |
| (c) | Other substantial breaches | No |
| (d) | Suitable alternative offered | No |
| (e) | Current tenancy = subletting | No |
| (f) | Demolition/reconstruction | Yes |
| (g) | Landlord's own occupation | Yes |

### Compensation (Grounds f & g)

- **Standard**: 1× rateable value
- **Long occupation** (14+ years): 2× rateable value

### Renewal Terms

New lease terms negotiated or determined by court:
- Market rent (current, not review date)
- Lease length (typically 5-15 years)
- Other terms "as agreed" or court decides

## Break Clauses

### Types

| Type | Description |
|------|-------------|
| **Mutual** | Either party can break |
| **Tenant only** | Only tenant can exercise |
| **Landlord only** | Rare; only landlord can break |
| **Rolling** | Can break at any time on notice |

### Break Conditions

**Common Requirements:**
- Notice period (3-6 months typical)
- Give vacant possession
- Pay all rent to break date
- Not be in material breach
- Make specified payments (dilapidations deposit)

### Break Notice Requirements

**Critical Points:**
- **Time**: Strictly on time (to the day)
- **Form**: As specified in lease
- **Service**: Correct address, method
- **Content**: Clear and unconditional

**Common Pitfalls:**
- Wrong date
- Conditional wording
- Served on wrong party
- Missing pre-conditions

### Validating Breaks

Before serving notice, verify:
- [ ] All rent paid to date
- [ ] No material breaches
- [ ] Correct notice period
- [ ] Correct form and content
- [ ] Correct service address
- [ ] Vacant possession achievable

## Dilapidations

### Schedule Types

| Type | When | Content |
|------|------|---------|
| **Interim** | During term | Repair only |
| **Terminal** | At lease end | Full schedule |
| **Quantified Demand** | Post-expiry | Costed schedule |

### Statutory Limitation (S18(1))

Damages limited to diminution in reversion value:
- If landlord redeveloping, may recover nothing
- If similar state lettable, may recover little
- Expert evidence often required

### Supersession

If landlord does works costing less than schedule:
- Tenant only liable for works done
- Must prove works superseded

### Negotiation Approach

**Landlord:**
- Early schedule (interim warnings)
- Detailed costed schedule
- Pursue diligently

**Tenant:**
- Challenge specification (betterment)
- S18 defence
- Negotiate settlement
